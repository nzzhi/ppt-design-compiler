# Theme Library

The MVP starts with three built-in themes:

| Theme ID | Best for | Design direction |
| --- | --- | --- |
| `business-report.v1` | Work reports, client briefings, industry analysis | White background, blue-gray structure, restrained accents |
| `academic-defense.v1` | Thesis defense, classroom presentation, research report | Light background, evidence-first layout, higher information density |
| `tech-roadshow.v1` | Product pitch, startup roadshow, technology solution | Dark high-contrast base, stronger hierarchy, lower density |

Theme files define design tokens, not rendered master slides. The renderer should use these tokens together with layout specs and slide plans.
